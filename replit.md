# AI Strength Coach

A personalized AI-powered weightlifting plan generator — athletes enter their sport, stats, and goals, and receive a structured weekly training program generated by OpenAI.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 8080)
- `pnpm --filter @workspace/ai-strength-coach run dev` — run the frontend (port 23740)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string
- Required env: `AI_INTEGRATIONS_OPENAI_BASE_URL`, `AI_INTEGRATIONS_OPENAI_API_KEY` — auto-set by Replit AI Integrations

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React + Vite, TailwindCSS, shadcn/ui, TanStack Query
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- AI: OpenAI via Replit AI Integrations proxy (gpt-5.4, SSE streaming)
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `lib/api-spec/openapi.yaml` — OpenAPI contract (source of truth)
- `lib/db/src/schema/workoutPlans.ts` — Drizzle schema for `workout_plans` table
- `artifacts/api-server/src/routes/workout/index.ts` — Workout generation + CRUD routes
- `artifacts/ai-strength-coach/src/` — React frontend

## Architecture decisions

- Workout generation uses SSE streaming so the plan appears word-by-word as OpenAI responds; the frontend consumes it via raw `fetch` + `ReadableStream`
- OpenAI access via Replit AI Integrations proxy — no API key required from users, billed to Replit credits
- Saved plans stored in PostgreSQL via Drizzle; the frontend can save, list, and delete plans
- Single-page layout: form on left, results on right (stacked on mobile)

## Product

- Athletes fill in sport, experience level, age, weight (optional), current stats, goals, and training days/week
- AI generates a structured weekly lifting program streamed in real-time
- Plans can be saved, browsed, and deleted from a slide-out drawer

## Gotchas

- After any OpenAPI spec change, always run codegen before writing routes or hooks
- The `generateWorkout` endpoint is SSE — do NOT use the generated React Query hook for it; use raw fetch on the client
- `pnpm run typecheck:libs` must pass before the api-server typecheck will see new DB schema exports
